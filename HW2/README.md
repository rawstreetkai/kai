# Homework 2 — VS Code Client Debugger

## Steps I used to debug client-side JavaScript locally

1. Installed **Visual Studio Code**.
2. Opened my web-programming folder in VS Code with **File → Open Folder**.
3. Installed a browser/debugging workflow using the built-in JavaScript debugger.
4. Opened `debug-demo.html` in a browser from VS Code.
5. Opened `debug-demo.js` and clicked in the left margin next to a line of JavaScript to set a **breakpoint**.
6. Started debugging from **Run and Debug** in VS Code.
7. Reloaded the page so execution stopped on the breakpoint.
8. Used **Step Over (F10)** to move through the JavaScript one line at a time.
9. Used the **Variables** and **Watch** areas to inspect the values of variables while the code was paused.
10. Stopped the debugger when finished.
