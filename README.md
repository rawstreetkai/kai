# CISC 2350 Homework

Fall 2026 — Information and Web Programming

This repository contains HW1–HW9 plus a simple `index.html` for navigation.

## Homework
- HW1 — HTML5/CSS3 calculator layout
- HW2 — VS Code client debugger steps + demo
- HW3 — JavaScript calculator with add/subtract/multiply/divide
- HW4 — State → City → County → Village dependent selections
- HW5 — `numOfDgitis()` digit-counting function
- HW6 — `capsToFront()`
- HW7 — reverse a sentence word by word
- HW8 — New York Times Article Search API page
- HW9 — Anthropic structured JSON → Make.com webhook automation

## Credentials / external services
HW8 requires the student's own New York Times API key at run time.

HW9 requires the student's own Anthropic API key and a Make.com Custom Webhook URL. These credentials are intentionally not stored in this public repository.
