# Homework 8 — NY Times API Search

Open `index.html`, enter a valid **New York Times API key**, enter a search term, and click **Search**.

The page sends a request to the New York Times Article Search API and displays up to 10 article headlines, summaries, and links.

The API key is intentionally **not committed to GitHub**. Add your own key at run time so the credential is not exposed in a public repository.
